# 🍽️ Java Restaurant

Sistema web para la gestión de un restaurante, desarrollado como **proyecto académico durante mi formación en el SENA**.

El proyecto integra un **frontend en HTML, CSS y JavaScript** con un **backend desarrollado en Java y Spring Boot**, conectado a una base de datos MySQL.

## 🛠️ Tecnologías

* ☕ Java
* 🌱 Spring Boot
* 🗄️ MySQL
* 🔗 Spring Data JPA
* 🌐 HTML
* 🎨 CSS
* ⚡ JavaScript
* 📖 REST API

## 📌 Funcionalidades

* Gestión de clientes.
* Gestión de empleados.
* Gestión de productos.
* Gestión de pedidos.
* Gestión de detalles de pedidos.
* Operaciones CRUD.
* Consulta y búsqueda de información.
* Comunicación entre frontend y backend mediante API REST.

## 🏗️ Arquitectura

El proyecto está dividido en frontend y backend:

```text
Java Restaurant
│
├── Front-end
│   ├── HTML
│   ├── CSS
│   └── JavaScript
│
├── Back-end
│   └── Spring Boot
│       ├── Controller
│       ├── Service
│       ├── Repository
│       ├── Model
│       └── Config
│
└── Base de datos
    └── MySQL
```

## 🚀 Ejecución

### Backend

1. Clonar el repositorio.
2. Abrir el proyecto backend en un IDE compatible con Java.
3. Configurar la conexión a MySQL.
4. Crear la base de datos correspondiente.
5. Ejecutar la aplicación Spring Boot.

### Frontend

Abrir el proyecto frontend y ejecutarlo utilizando un servidor local.

El frontend se comunica con la API REST del backend para realizar las operaciones del sistema.
